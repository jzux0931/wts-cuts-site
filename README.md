# WT’s Military Cuts — website preview

A responsive two-page preview for WT’s Military Cuts. It presents the shop, its service categories, photos, location, and contact options. The Services page lists its services in five categories with links to the shop’s public booking flow.

This is a preview for WT's to review. Square continues to handle bookings and payments; service details, photos, hours, and copy will need approval before launch.

## Implementation

- HTML, Sass, vanilla JavaScript, and Vite.
- Responsive navigation and an accessible, manually controlled photo carousel.
- Shop photos currently load from the public Squarespace CDN. Wanda should approve the selection and their use before a business launch.
- No private Square account access, backend, database, or checkout is included.
